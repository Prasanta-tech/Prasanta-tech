## ◈ Featured Projects

### 1. LoreWeaver --- Asynchronous AI Narrative Engine

An AI-powered interactive storytelling application that generates
multi-path stories. Users can explore branching storylines, with
AI-generated story nodes validated and stored for further interaction.

  -----------------------------------------------------------------------
  Attribute                           Details
  ----------------------------------- -----------------------------------
  **Stack**                           Python, FastAPI, React.js,
                                      PostgreSQL

  **AI Integration**                  LangChain, OpenAI API

  **Data Validation**                 Pydantic

  **Cloud & Deployment**              AWS, CI/CD

  **Key Engineering**                 Background processing for
                                      long-running AI requests and
                                      frontend polling
  -----------------------------------------------------------------------

**What I worked on** - Developed the application using React.js and
FastAPI. - Integrated OpenAI models through LangChain to generate
interactive story content. - Used Pydantic to validate structured AI
responses before storing branching story nodes in PostgreSQL. -
Implemented background tasks to prevent slow AI requests from blocking
API responses. - Built a polling mechanism that checks for task updates
every five seconds. - Deployed the application using AWS infrastructure
and CI/CD pipelines.

**Repository:** [LoreWeaver](https://github.com/Prasanta-tech)

### 2. Secure AI Document Analyst Engine

An AI-powered document analysis application that helps users search and
ask questions about long financial reports. It uses document retrieval
to provide answers grounded in the uploaded documents.

  Attribute             Details
  --------------------- ----------------------------------------------
  **Stack**             React.js, FastAPI
  **Database**          Supabase (PostgreSQL + pgvector)
  **AI Integration**    OpenAI API
  **Deployment**        Railway
  **Key Engineering**   Document retrieval and source-linked answers

**What I worked on** - Built an AI chat application to search and
analyze hundreds of long financial reports. - Developed the backend
using Python and FastAPI. - Used Supabase to store document data and
support vector-based retrieval with pgvector. - Connected the React
frontend with the backend AI workflow. - Implemented source-linked
answers so users can inspect the document paragraph supporting a
response. - Deployed the application using Railway.

**Repository:** [Secure AI Document Analyst
Engine](https://github.com/Prasanta-tech)
